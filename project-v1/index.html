01 / 国家级创新项目 2024.07–2025.07

长航时波浪航行器设计与制造

核心成员 · “海洋探险者”

项目概述

基于前期双功能水翼理论与仿真模型，调整变量参数探究其对水翼推进效率与能量捕获效率的影响规律；并创新设计集成陶瓷轴承与弹性限位件的转轴固定装置，提升复杂海况下的耐久性。

本人贡献
  • 使用 SolidWorks 完成航行器舱体三维建模
  • 基于 STAR-CCM+ 二维非定常 CFD 模型，系统研究设计参数对水动力性能的影响规律
  • 处理仿真数据并生成可视化图表，定量对比不同构型的推进效率与运动响应，验证双功能扑翼水翼的优越性
  • SolidWorks
  • STAR-CCM+
  • CFD
  • 水动力
02 / 国家发明专利 2025.04–2025.11

水翼转轴固定装置

第三发明人 · 波浪推进海洋航行器

项目概述

针对水下牵引机转轴磨损严重、寿命短的问题，引入陶瓷轴承与特殊结构轴承盖套以显著降低摩擦系数，并设计弹性水翼限位杆与滑动轨道配合吸收冲击载荷。

本人贡献
  • 负责海洋航行器舱体的 SolidWorks 三维建模
  • 主导构建含总体视图、剖视图与爆炸图的工程图，完成零部件序号标注
  • 参与部分专利说明书撰写与图纸表达

03 / 论文 2026.01–至今

Q-Learning 路径规划

第一作者 · ICMLM 2026 录用

项目概述

构建基于马尔可夫决策过程（MDP）的 Q-learning 模型，通过多场景仿真分析 ε-greedy 衰减机制与学习率（α）对累积奖励与路径质量的影响，实现无先验地图下的无碰撞路径求解。

本人贡献
  • 作为第一作者，负责研究思路梳理与实验方案设计
  • 参与搭建二维栅格环境下的 Q-learning 路径规划模型
  • 完成不同 ε 衰减策略与学习率参数的对比实验及结果分析，并负责论文撰写与修改
