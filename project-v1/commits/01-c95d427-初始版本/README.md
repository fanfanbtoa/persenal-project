# 范博韬 · 个人主页原型 v1

一个面向 HR 访客的单页个人主页。主人公是哈尔滨工程大学自动化专业大四学生，已保研至浙江大学电子信息专业。

页面按三个部分组织：**个人简介 → 专业能力与探索方向 → 数字分身**，顶部导览与这三个部分一一对应。

包含：

- 姓名旁可本地上传的头像、姓名与一句话介绍
- 个人信息速览：身份、去向、关注方向与兴趣
- 可通过本地 Node 调用 DeepSeek 的「数字分身」聊天区，并保留本地知识库回退
- 青绿色水面插画作为全站固定背景，桌面与移动端自动适配（已去除原图的时间/日期文字）
- 桌面端 / 移动端响应式布局

整体视觉为深色水面插画背景 + 青绿高光与奶油色点缀的玻璃质感卡片，强调安静、通透和科技感；背景图使用项目自带的 `bg-water.jpg`，不依赖任何外部图片或前端框架。

## 预览方式

有两种方式：

**只查看页面 / 使用本地知识库模式**

双击 `preview.bat`，或直接双击 `index.html`。不需要安装依赖、不需要构建、不需要启动服务器；聊天区会使用 `app.js` 里的本地知识库。

先按下面的「启动 DeepSeek 对话」配置 `.env`，再双击 `start-server.bat`，浏览器会打开 `http://127.0.0.1:3000/`。这种方式需要 Node.js，但不需要安装任何 npm 依赖。

## 数字分身怎么工作

数字分身现在有两层：

1. **DeepSeek 模式（推荐）**：通过本地 Node 服务调用 DeepSeek，前端只请求 `/api/chat`，API Key 保存在服务端 `.env` 中。
2. **本地知识库回退**：没有配置 Key、直接双击打开 `index.html`、后端未启动或模型请求失败时，自动使用 `app.js` 里的本地知识库回答。

无论哪种模式，快捷问题、Enter 发送、Shift + Enter 换行、重新开始对话都可用。

## 启动 DeepSeek 对话

1. 把 `.env.example` 复制为 `.env`
2. 打开 `.env`，填入 DeepSeek Key：

```env
DEEPSEEK_API_KEY=你的 DeepSeek Key
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-chat
PORT=3000
```

3. 双击 `start-server.bat`，或在本目录运行：

```bash
node server.mjs
```

4. 打开 `http://127.0.0.1:3000/`

配置成功时，数字分身侧栏显示「在线 · DeepSeek」；未配置时显示「本地问答」。Key 只存在于服务端，不会出现在前端代码里。

> 请不要把 `.env` 提交到 Git，也不要把 Key 发到聊天里。`.env.example` 应始终保持空白模板，不要在里面填真实 Key。`server.mjs` 默认只监听 `127.0.0.1`，适合本机使用。

### 本地知识库回退

知识库在 `app.js` 的 `KB` 数组中，直接修改 `answer` 即可更新固定回答；快捷问题在 `INITIAL_PROMPTS`，追问推荐在 `FOLLOW_UPS`。

## 头像上传怎么工作

点击姓名旁的头像即可选择本地图片（JPG / PNG / WebP，8MB 以内）：

- 图片会压缩到最长边 512px，并同步到首屏头像、数字分身侧栏头像与聊天消息头像
- 使用 `localStorage` 保存在当前浏览器，刷新后仍可见

注意：这是**本机预览**能力，上传结果不会上传到服务器，因此只对当前浏览器可见。正式发布给 HR 看时，应把确定好的头像图片直接放进项目并作为默认头像。

## 想替换的内容

- **正式头像**：当前默认头像是「范」字占位，可通过本地上传预览。正式发布时建议把选定的真人头像文件放进项目，作为所有访客看到的默认头像。
- **联系方式 / 简历入口**：用户资料中暂未提供邮箱和简历，所以这一版没有放虚构信息。正式上线时建议补充真实邮箱或简历 PDF 下载入口。
- **能力描述**：`app.js` 中「本科阶段能力」回答是根据自动化专业背景做的概括，建议本人按真实课程、项目经历再校准一次。
- **项目经历**：这一版聚焦在“快速看懂我是谁”，还没有展开具体项目；下一版可以补 1–2 个真实项目卡片。

## 已知边界

- 没有 `.env`、没有启动 Node 服务，或直接双击 `index.html` 时，数字分身使用本地知识库，不会调用模型。
- 配置 DeepSeek 后，用户的问题和最近对话会发送给 DeepSeek 用于生成回答；不要输入敏感信息。
- 当前版本是本地 Node 服务，默认只监听 `127.0.0.1`，不能直接作为公网服务使用。
- 页面内容是静态的，更新内容需要修改 HTML / JS 或 `.env` 后重启服务。
- 动画已适配 `prefers-reduced-motion`。
- `app.js` 中的人物能力表述是原型阶段的概括文案，建议上线前由本人确认。
