# 版本记录

> 版本规则：每次上传 GitHub 都在 `project-v1/commits/` 下生成 `NN-<哈希>-<改了什么>/` 快照，并写 `说明.md`；`说明.md` 中的「这次改了什么」用于区分每个版本。平时改完页面不用生成快照；需要上线时运行 `project-v1/同步.bat`（或让 AI 同步），它会按这次改了什么生成快照、提交并推送 E 盘和 GitHub。
