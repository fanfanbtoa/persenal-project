# 提交历史存档

这个文件夹按 Git / GitHub 的提交顺序，保存每次提交时 `project-v1` 的完整代码快照，方便单独查看和对比，不会和当前正在使用的站点混在一起。

**以后每次上传 GitHub 都按这个规则执行：**

1. 在 `project-v1/commits/` 下新建 `NN-<提交哈希>-<本次改了什么>/`；
2. 文件夹里放该版本的完整代码，并写一个 `说明.md`，其中「这次改了什么」必须写清楚；
3. 在下面表格里新增一行；
4. 提交并推送后，GitHub 上就能按版本查看和对比。

平时改完页面**不用生成快照**；需要上线时运行 `project-v1/同步.bat`，输入这次改了什么，它会先按描述生成快照、写 `说明.md`、更新表格，再推 E 盘和 GitHub。
